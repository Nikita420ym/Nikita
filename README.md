# 🚀 Электронная торговая площадка: Оборудование для автомоек
Учебный проект по разработке архитектуры интернет-каталога для подбора автомоечного оборудования. Главная особенность системы — механизм «скрытой регистрации»: пользователь может просматривать категории и добавлять товары в корзину без заполнения форм, профиль создается в фоне. Процессы оформления заказа и оплаты в текущей версии не реализуются.

 * 📦 **Структура каталога:** Описание иерархии категорий товаров для автомоечного бизнеса.
